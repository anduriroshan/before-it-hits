AI agents

Fourteen agents, one hard boundary

Gemini understands the question, reads local-language reporting and documents, writes in Malayalam and English, and checks its own drafts. The engine computes every ranking, count and depth. No number reaches the user unless a tool produced it.

Gemini does

  • Understand a free-text question about the box you drew
  • Resolve local place names people actually use
  • Read national bulletins, city PDFs and budget rules
  • Read local-language news and judge whether reports describe the same event
  • Check which preparations the city is actually allowed to make, and explain trade-offs
  • Write the briefing and the area messages
  • Check every claim in the draft against the results

The engine does — no language model involved

  • Read the elevation for the box
  • Fill depressions, compute flow direction and accumulation
  • Rank pooling spots and their contributing area
  • Clip the official hazard layer
  • Count who is nearby and which routes are affected
  • Rank preparations by coverage per rupee
  • Same box + same seed → same answer, every time

One question, traced

Ward officer, Kochi — drew a 5.2 km² box over Edappally, 14:05 “Which parts of this area collect water first, and what should we clear before the season?”

Runtime agents — answer a question

Push agent — prepares a briefing before anyone asks

Harness agents — generate the mess we must survive

These exist only inside the test harness. They never decide what physically happens — the world state is computed in code from a fixed seed, and these agents only describe and distort it.

Build-time agents — onboard a region

Contracts between agents and tools

Every hand-off is a typed object. The Verifier checks the final text against these, not against what an agent remembers saying.

# Python ADK — structure sketch, not final code
scenario = LlmAgent(name="scenario", model=FLASH, tools=[area_bounds, gazetteer_lookup], output_key="spec")
forecast = LlmAgent(name="forecast", model=FLASH, tools=[weather_forecast, agency_bulletin, return_period], output_key="forcing")
analyse  = FunctionTool(analyse_area)      # engine: terrain → fill → flow → pooling index. deterministic
official = FunctionTool(official_layer)    # engine: clip KSDMA raster by return period. display as published
news     = LlmAgent(name="news", model=FLASH, tools=[gdelt_search, dedupe_clusters], output_key="reporting")
planner  = LlmAgent(name="planner", model=PRO, tools=[rank_preparations, capability_notes], output_key="plan")
narrator = LlmAgent(name="narrator", model=FLASH, instruction=NARRATE, output_key="draft")
verifier = LlmAgent(name="verifier", model=PRO, tools=[extract_claims, results_bundle, data_honesty, approve])
write    = LoopAgent(name="write_and_check", sub_agents=[narrator, verifier], max_iterations=3)

coordinator = LlmAgent(
    name="coordinator", model=PRO,
    instruction=("Never state a number yourself. Every figure must come from a tool result. "
                 "Never describe output as a forecast, a depth, or an instruction to dispatch."),
    tools=[AgentTool(scenario), AgentTool(forecast), analyse, official,
           AgentTool(news), AgentTool(planner), AgentTool(write)],
)
